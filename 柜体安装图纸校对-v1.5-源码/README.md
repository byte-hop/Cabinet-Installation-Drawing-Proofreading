# 柜图校对

柜体安装说明书自动核对工具。打开整套安装图 PDF 后，软件会自动识别领客屋、遨森、英驰三类版式，读取五金清单、板件清单和每个安装步骤的用量表，自动检查：

- 各步骤的五金用量合计，与五金清单需求数量是否一致
- 步骤中是否使用了清单外的五金编号
- 同一张用量表是否重复编号、数量为 0，或数量不能被 `×N` 重复倍数整除
- 步骤和装配总览中是否出现清单外的板件编号
- 清单板件是否漏用、总览是否漏标
- `×N` 重复步骤的板件用量是否与清单数量矛盾
- 步骤编号是否缺号或重号
- 用量表标注与图形字母标注是否对应
- PDF 是否缺少可提取文字层
- 支持把 PDF 从资源管理器直接拖入窗口读取
- 支持桌面圆形悬浮球：可调大小、自定义图片，拖入 PDF 直接核对

所有解析在本机离线完成，不上传图纸，不调用云端 OCR 或大模型。

## 免 Python 单文件版

`发布\柜图校对.exe` 是已经打包好的 Windows 单文件程序，目标电脑无需安装 Python，也不需要联网：

1. 把 `柜图校对.exe` 放到有写入权限的文件夹。
2. 双击运行，程序会直接打开桌面窗口，不会跳转到系统浏览器。
3. 点击关闭按钮时，首次可选择最小化到圆形悬浮球或退出；选择“最小化到悬浮球”后会记住该选择，后续关闭直接最小化。

桌面窗口使用 Windows 自带的 Microsoft Edge WebView2 运行。Windows 10 / 11 通常已自动安装；如果启动时提示缺少 WebView2 Runtime，可安装微软官方运行库后重试。

首次运行会在 exe 同目录创建 `data` 文件夹；如果该目录不可写，会自动改用 `%LOCALAPPDATA%\CabinetDocCheck\data`。程序未做商业代码签名，Windows SmartScreen 首次运行可能提示“已保护你的电脑”，可点击“更多信息 → 仍要运行”。

## 直接启动

1. 安装 Python 3.11 或更高版本，安装时勾选 `Add Python to PATH`。
2. 双击 `启动柜图校对.bat`。
3. 首次运行若缺少 `pymupdf` / `openpyxl` / `pywebview`，启动器会自动执行 `pip install -r requirements.txt`。
4. 桌面窗口打开后，点击“打开图纸”选择 PDF，或直接把 PDF 拖进窗口。

也可以在命令行启动：

```bat
cd /d "本目录"
pip install -r requirements.txt
python app.py
```

默认会启动桌面窗口。内部本地服务地址为 `http://127.0.0.1:8765/`，端口被占用时会自动向后寻找可用端口。诊断时可使用 `python app.py --browser` 临时改用系统浏览器。

## 使用流程

1. 把 PDF 从资源管理器拖入窗口，或点击“打开图纸”选择文件；松开后自动开始解析。
2. 在“校验总览”查看总体结论、9 项检查和识别到的五金类数。
3. 在“五金核对”逐项查看清单需求、备用、步骤合计、差额和使用步骤。
4. 在“板件核对”查看每个板件编号被哪些步骤引用、是否漏用或重复矛盾。
5. 在“步骤明细”查看每一步的板件与五金用量，重复步骤同时显示每套用量。
6. 在“问题清单”按错误、待确认、提示筛选；点击结果可直接定位到 PDF 页面和图形区域。
7. 点击“导出报告”，得到包含 6 个工作表的 Excel 文件。

## 拖拽打开图纸

可以直接把 PDF 从 Windows 资源管理器拖到程序窗口任意位置。窗口出现蓝色投放提示后松开鼠标即可开始解析，不需要先点“打开图纸”。

- 一次读取一份 PDF；拖入多个文件时只读取第一个。
- 文件必须为 `.pdf`，大小不超过 120 MB。
- 非 PDF 或超限文件会在底部给出明确提示，不会进入解析队列。

## 桌面悬浮球

点击主窗口右上角关闭按钮时，首次会弹出提示：

- **最小化到悬浮球**：隐藏主窗口，在桌面右下角保留圆形悬浮球。软件会记住此选择，后续关闭直接最小化，不再询问。
- **退出程序**：关闭主窗口和悬浮球。下次启动后点击关闭按钮，会重新弹出提示。
- **取消**：回到主界面，不改变已有设置。

悬浮球默认 `64 × 64` 像素，接近 Windows 桌面图标大小；可在主界面顶部“悬浮球”设置中调整 `44–160` 像素，也可在悬浮球右键/齿轮菜单里直接拖动大小滑块。悬浮球按圆形裁剪，不显示方形底色，也不会出现在任务栏或 Alt+Tab 列表中。

- 左键单击悬浮球：恢复主界面。
- 右键悬浮球或点击小齿轮：返回主界面、更换图片、调整大小或退出程序。
- 把 PDF 拖到悬浮球上：悬浮球会展开为椭圆并显示“将图纸拖拽进来，开始核对！”，松开后自动识别模板并开始核对。
- 核对成功后自动恢复主界面并载入结果；非 PDF、超过 120 MB 或无法识别的图纸会在悬浮球内提示，不进入解析。
- 悬浮球图片支持 PNG、JPG、WEBP、GIF、BMP，最大 12 MB，建议使用正方形图片。自定义图片保存在 `data/widget/avatar.*`，大小与关闭偏好保存在 `data/widget/settings.json`。
- 如果希望关闭时重新询问，在“悬浮球”设置中取消勾选“关闭窗口时直接最小化到悬浮球，不再询问”。

## 本地知识库与加速

程序会在本机 `data/knowledge/knowledge.db` 建立 SQLite 知识库，不需要联网，也不会上传图纸。

- 文档指纹缓存：按 PDF 文件内容的 SHA-256 记录解析结果。再次打开同一份图纸时跳过 PDF 文字层解析，直接复用缓存，并重新应用当前修正记忆。
- 修正记忆：在问题清单中点击“标记误报并记住”或“确认为问题”，软件会按“模板 + 规则编号 + 问题标题”记住判断。后续同模板图纸遇到相同结果时自动过滤或标注。
- 知识库面板：点击顶部“知识库”，可以查看缓存图纸、累计命中、首次/缓存耗时、学习记录，并可删除单条记忆或清空缓存/学习记录。
- 版本升级：解析引擎版本变化后，旧文档缓存会自动失效，避免沿用过期结果。

这不是神经网络训练，也不需要大量样本。对固定版式图纸，规则校验 + 人工反馈记忆 + 文档缓存更可控；三套模板的识别准确率由规则保证，速度由缓存提升。

注意：标记误报会改变后续同模板的判断，请只在确认该结果确实为误报时使用。误操作可在知识库面板删除对应记忆。

## 判定口径

- 五金清单中的 `x66+2` 解释为“需求 66 件 + 备用 2 件”。核对以 66 件为准，备用数量单独展示。
- 英驰版式步骤卡右上角的 `×8` 解释为“该步骤重复 8 次”，用量表中的数量按整套总用量处理。领客屋 / 遨森版式的步骤用量表按单套用量处理，图中的 `×2` 安装动作不会误当成重复倍数。
- 遨森版式板件清单中的编号是图形化数字，读取时按清单网格顺序还原为 1–24；步骤图中的板件编号仍逐处识别并检查。
- 领客屋版式支持 `CL / CR / DL / DR` 等双字母五金编号，以及 `H-1 / H-2` 形式的同一五金分件标注。
- 同一板件在同一张步骤图中出现两次，可能是爆炸图与装配图两个视图，因此列为“提示”，需要人工确认，不直接判错。
- 用量表列了某五金、但图中没有字母标注时，部分模板会用图形直接示意，因此同样列为“提示”。
- 板件编号是否“错标”的可自动判断范围是：清单外编号、总览与步骤不一致、重复模块数量不可能、同图异常重复。若两个合法编号被互换，且数量约束无法暴露问题，仍需人工复核。

## 严重程度

| 级别 | 含义 | 处理方式 |
| --- | --- | --- |
| 错误 | 数量合计不一致、未知编号、重复模块数量不可能、步骤缺号或重号等硬性问题 | 必须修正后重新导出 PDF |
| 待确认 | 清单板件未引用、总览漏标、用量不能被 `×N` 整除等 | 人工判断是模板表达差异还是实际错误 |
| 提示 | 同图多次标注、用量表有编号但图中未标 | 结合具体图纸习惯复核，通常可忽略 |

## Excel 报告

导出的报告包含 6 个工作表：

- `校验总览`：总体结论、统计数据和 9 项检查结果
- `五金核对`：清单需求、备用、步骤合计、差额、使用步骤与定位信息
- `板件核对`：清单数量、引用步骤、首次出现、同图最多标注和状态
- `步骤明细`：每一步的板件编号、五金总量、每套用量和关联问题
- `问题清单`：按严重程度排序的问题、修改建议和 PDF 页码
- `检查说明`：规则口径与使用边界

## 支持模板与自动识别

- `领客屋` 版式：22 页，板件清单 + 五金清单 + 装配总览 + 按 `STEP n` 划分的双步骤卡。
- `遨森` 版式：24 页，爆炸图 + 图形化 Parts 网格 + 14 类五金表 + 32 个步骤。
- `英驰` 版式：19 页，Parts List + 五金清单 + `×N` 编号步骤卡。

软件读取页面内容后自动选择对应解析逻辑，不需要手动切换模板。界面侧栏会显示“领客屋版式”“遨森 24 页版式”或“英驰版式”。

## 三套示例实测结果

### 领客屋.pdf

- PDF 共 22 页
- 五金清单 18 类，需求合计 166 件
- 板件清单 17 类，总数量 22 件
- 安装步骤 25 个，其中 22 个步骤带五金用量表
- 五金步骤用量合计 167 件，报告 H 多 2 件、L 清单 1 件但未使用
- 硬性错误 2，待确认 0，提示 0

### 遨森.pdf

- PDF 共 24 页
- 五金清单 14 类（A–N），需求合计 246 件，备用合计 13 件
- 板件清单 24 类，总数量 36 件
- 安装步骤 32 个，其中 30 个步骤带五金用量表
- 五金步骤用量合计 248 件，报告 N 多 2 件
- 硬性错误 1，待确认 0，提示 14

### 英驰.pdf

- PDF 共 19 页
- 五金清单 18 类，需求合计 410 件，备用合计 15 件
- 板件清单 17 类，总数量 61 件
- 安装步骤 25 个，其中 6 个为 `×8` 重复步骤
- 五金步骤用量合计 410 件，与清单需求完全一致
- 硬性错误 0，待确认 0，提示 2

## 适用范围与边界

- 当前版本内置领客屋、遨森、英驰三类版式，并会按页面内容自动识别。
- 同一模板如果改变清单位置、字号、步骤卡数量或编号写法，仍可能需要补充识别规则。
- 依赖 PDF 文字层。扫描件、图片型 PDF、文字已转曲的图纸无法自动识别。
- 其他模板如果版式、字号、表格位置变化较大，需要调整 `core/pdf_parser.py` 中的识别参数。
- 软件用于发现“数量与编号的形式性矛盾”，不能替代设计师对结构、装配关系和工艺的判断。

## 常见问题

**页面显示“未识别到五金清单”怎么办？**

确认 PDF 有文字层，并包含五金清单与板件清单。扫描件或转曲图纸需要先从 CAD 重新导出带文字的 PDF；若页面标题和排版属于新的模板，则需要继续补充识别规则。

**为什么用量表有、图中却提示未标注？**

有些五金在图纸中用实物示意而不标字母。该情况只作提示，不影响数量合计判定。

**图纸会上传吗？**

不会。服务只监听 `127.0.0.1`，所有文件解析、图片渲染和报告生成都在本机完成。
